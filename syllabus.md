# AI Engineer -- Study Syllabus

> Comprehensive preparation guide covering core competencies expected of a
> production-grade AI engineer. Organized into 5 phases and 14 modules with
> 71 topics total. Each topic should be understood deeply enough to explain
> clearly under any condition.
>
> See `ROADMAP.md` for the visual learning path, prerequisite chains, and
> recommended study tracks.

---

## Phase 1: Foundations

### Module 01: Prompt Engineering

1. Fundamentals and patterns
2. Chain-of-thought and reasoning techniques
3. System prompts and persona design
4. Prompt testing and versioning
5. Few-shot, zero-shot, and in-context learning

### Module 02: Backend Fundamentals

6. Async patterns and concurrency
7. Message queues and event-driven architecture
8. N+1 query problem and resolution
9. Sharding and pagination strategies

---

## Phase 2: Core AI Engineering

### Module 03: Retrieval-Augmented Generation (RAG)

10. RAG fundamentals
11. Chunking strategies
12. Vector database and indexing
13. Hybrid search and reranking
14. Embedding ambiguity and limitations
15. RAG evaluation tooling and metrics

### Module 04: Tool Use & MCP

16. MCP versus API -- differentiation and trade-offs
17. MCP tool selection and architecture
18. Function calling and structured outputs
19. A2A protocol

### Module 05: Model Operations

20. Context window and token management
21. Model migration and evaluation discipline
22. Fine-tuning fundamentals -- LoRA and QLoRA
23. Quantization -- GPTQ, AWQ, and GGUF
24. Model serving and inference optimization
