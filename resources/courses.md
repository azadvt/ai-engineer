# Recommended Courses

**Difficulty Levels:** Beginner | Intermediate | Advanced

## Study Path Suggestions

**Getting started (0-3 months):**
1. 3Blue1Brown Neural Networks Series (visual intuition)
2. Andrej Karpathy's Zero to Hero (hands-on fundamentals)
3. ChatGPT Prompt Engineering for Developers (practical LLM skills)

**Building depth (3-6 months):**
1. fast.ai Practical Deep Learning (comprehensive applied DL)
2. Hugging Face NLP Course (transformer ecosystem)
3. DeepLearning.AI short courses on RAG and agents

**Going advanced (6-12 months):**
1. CS224N or CS229 (theoretical depth)
2. Deep Learning Specialization (structured certificate path)
3. MLOps Specialization (production skills)
