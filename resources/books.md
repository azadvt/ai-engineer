# Recommended Books

A curated list of books for AI engineers, organized by category and difficulty level.

**Difficulty Levels:** Beginner | Intermediate | Advanced

---

## Foundations

Core machine learning and AI concepts that every AI engineer should understand.

| Title | Author(s) | Description | Difficulty |
|-------|-----------|-------------|------------|
| *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* (3rd ed.) | Aurelien Geron | Practical introduction to ML from classical algorithms to deep learning, with hands-on code examples | Beginner |
| *Deep Learning* | Ian Goodfellow, Yoshua Bengio, Aaron Courville | Comprehensive theoretical treatment of deep learning foundations, from linear algebra to generative models | Advanced |
| *The Hundred-Page Machine Learning Book* | Andriy Burkov | Concise overview of core ML concepts and algorithms for practitioners who want breadth without excessive depth | Beginner |
| *Mathematics for Machine Learning* | Marc Peter Deitmar, Aldo Faisal, Cheng Soon Ong | Builds the mathematical foundations (linear algebra, calculus, probability) required for understanding ML algorithms | Intermediate |

## AI Engineering

Building applications powered by LLMs, RAG systems, and modern AI infrastructure.

| Title | Author(s) | Description | Difficulty |
|-------|-----------|-------------|------------|
| *AI Engineering* | Chip Huyen | End-to-end guide to building AI applications, covering LLM APIs, RAG, fine-tuning, evaluation, and deployment | Intermediate |
| *Building LLM Apps* | Valentina Alto | Practical guide to building production applications with large language models using Python | Intermediate |
| *Designing Machine Learning Systems* | Chip Huyen | Framework for designing reliable, scalable ML systems from data engineering through deployment and monitoring | Intermediate |
| *Natural Language Processing with Transformers* (Revised) | Lewis Tunstall, Leandro von Werra, Thomas Wolf | Hands-on guide to transformer architectures and NLP tasks using the Hugging Face ecosystem | Intermediate |

## System Design

Designing and scaling large-scale software and ML systems.

| Title | Author(s) | Description | Difficulty |
|-------|-----------|-------------|------------|
| *Designing Data-Intensive Applications* | Martin Kleppmann | Foundational text on distributed systems, data storage, and processing -- essential background for any AI system at scale | Intermediate |
| *System Design Interview* (Vol. 1 and 2) | Alex Xu | Structured approach to system design problems, useful for both interviews and real-world architecture decisions | Intermediate |
| *Machine Learning System Design Interview* | Ali Aminian, Alex Xu | Covers ML-specific system design including recommendation systems, search ranking, and model serving | Intermediate |

## Career and Leadership

Professional growth, team dynamics, and navigating the AI industry.

| Title | Author(s) | Description | Difficulty |
|-------|-----------|-------------|------------|
| *The Staff Engineer's Path* | Tanya Reilly | Guide to technical leadership beyond the management track, covering influence, decision-making, and cross-team impact | Intermediate |
| *Engineers Survival Guide* | Merih Taze | Practical career advice for software engineers on communication, visibility, and navigating organizations | Beginner |
| *An Elegant Puzzle: Systems of Engineering Management* | Will Larson | Explores engineering management challenges including team sizing, technical debt, and organizational design | Intermediate |
