# Module 13: Decision Models

**Phase 5 -- Specializations**

---

## Description

Emerging decision-focused AI models and structured reasoning. This module covers open-weight decision models (Laya), hosted decision APIs (Jev), dual-process thinking applied to AI, structured reasoning in agent architectures, and metacognition for self-evaluating AI systems.

## Learning Objectives

- Understand Laya and open-weight decision model architectures and use cases
- Integrate Jev and hosted decision APIs into AI application workflows
- Apply System One/Two thinking concepts to design faster and more deliberate AI reasoning
- Implement structured reasoning patterns within agent systems
- Build metacognition and self-evaluation capabilities into AI pipelines

## Prerequisites

- Phase 2 completion ([Module 03](../03-rag/), [Module 04](../04-tool-use-mcp/), [Module 05](../05-model-operations/))
