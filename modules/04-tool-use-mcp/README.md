# Module 04: Tool Use and MCP

**Phase 2 -- Core AI Engineering**

---

## Description

Connect AI models to external tools and APIs. This module covers the Model Context Protocol (MCP), function calling patterns, structured outputs, and the emerging Agent-to-Agent (A2A) protocol. Understanding tool use is essential for building AI systems that interact with the real world.

## Learning Objectives

- Compare MCP and traditional API approaches, selecting the right one for a given use case
- Design MCP tool architectures with appropriate selection and routing logic
- Implement function calling with structured outputs for reliable tool invocation
- Understand A2A (Agent-to-Agent) protocol for inter-agent communication
