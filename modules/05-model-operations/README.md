# Module 05: Model Operations

**Phase 2 -- Core AI Engineering**

---

## Description

Manage, evaluate, optimize, and serve AI models in production. This module covers the full lifecycle of model operations, from context window management and migration strategies through fine-tuning techniques and inference optimization. Essential for maintaining reliable AI systems at scale.

## Learning Objectives

- Manage context windows and token budgets effectively across different model families
- Plan and execute model migrations with structured evaluation discipline
- Apply fine-tuning techniques (LoRA, QLoRA) to adapt models for specific domains
- Understand quantization methods (GPTQ, AWQ, GGUF) and their trade-offs
- Optimize model serving and inference for latency, throughput, and cost
