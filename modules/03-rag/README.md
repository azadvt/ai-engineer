# Module 03: Retrieval-Augmented Generation (RAG)

**Phase 2 -- Core AI Engineering**

---

## Description

Build retrieval-augmented generation systems from scratch. RAG is the most common AI engineering pattern in production, combining information retrieval with generative models to produce grounded, accurate outputs. This module covers the full RAG pipeline from chunking through evaluation.

## Learning Objectives

- Design end-to-end RAG pipelines including ingestion, retrieval, and generation stages
- Select and implement appropriate chunking strategies for different document types
- Configure vector databases and indexing schemes for efficient similarity search
- Combine hybrid search with reranking to maximize retrieval quality
- Evaluate RAG systems using established metrics and tooling
