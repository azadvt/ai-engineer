# Module 12: Multimodal AI

**Phase 5 -- Specializations**

---

## Description

Extend AI systems beyond text to images, audio, video, and combined modalities. This module covers vision-language models, speech processing, image generation, multi-modal RAG, and video understanding. Multimodal capability is increasingly expected in production AI systems.

## Learning Objectives

- Work with vision-language models for image understanding and visual question answering
- Integrate audio and speech capabilities using Whisper, TTS, and related tools
- Understand image generation pipelines and diffusion model architectures
- Build multi-modal RAG systems that retrieve and reason across text, images, and audio
- Apply video understanding techniques for temporal and visual analysis

## Prerequisites

- Phase 2 completion ([Module 03](../03-rag/), [Module 04](../04-tool-use-mcp/), [Module 05](../05-model-operations/))
