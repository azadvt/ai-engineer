# Module 11: Engineering Practice

**Phase 4 -- Production and Scale**

---

## Description

Level up from individual contributor to technical leader in AI engineering. This module covers architecture ownership, AI-assisted development discipline, code review practices for AI-generated code, and leadership and mentoring skills. These are the qualities that distinguish senior AI engineers.

## Learning Objectives

- Take ownership of architectural decisions and defend them with clear reasoning
- Establish disciplined workflows for AI-assisted development that maintain code quality
- Conduct effective code reviews specifically tailored for AI-generated code
- Demonstrate leadership and mentoring signals expected at senior engineering levels

## Prerequisites

- Phase 2 completion ([Module 03](../03-rag/), [Module 04](../04-tool-use-mcp/), [Module 05](../05-model-operations/))
