# Module 06: Agentic Systems

**Phase 3 -- Advanced Patterns**

---

## Description

Design autonomous AI agents that can plan, reason, and act. This module covers the distinction between agents and workflows, guardrail enforcement, loop prevention, multi-agent coordination, and human oversight patterns. Understanding agentic design is critical for building reliable autonomous systems.

## Learning Objectives

- Distinguish between agentic and workflow-based architectures and select appropriately
- Implement guardrails and threshold enforcement to keep agents safe and predictable
- Design loop prevention mechanisms to avoid runaway agent behavior
- Coordinate multiple agents with clear communication and task delegation patterns
- Integrate human-in-the-loop checkpoints for high-stakes decisions
