# Module 07: Agent Frameworks

**Phase 3 -- Advanced Patterns**

---

## Description

Evaluate and use popular agent frameworks for building AI-powered systems. This module covers major frameworks including LangGraph, CrewAI, AutoGen, and LlamaIndex agents. Critically, it also covers when to use a framework versus building custom agent infrastructure.

## Learning Objectives

- Build agents using LangGraph, CrewAI, AutoGen/AG2, and LlamaIndex
- Compare frameworks across dimensions of flexibility, complexity, and production-readiness
- Apply a structured framework selection methodology based on project requirements
- Know when to abandon frameworks and build custom agent infrastructure instead
